# Front- та BackEnd-технології веб-застосувань

Репозиторій містить практичні завдання та командний навчально-дослідницький проєкт, виконані в межах вибіркової дисципліни **«Front- та BackEnd-технології веб-застосувань»** (НаУКМА, Факультет інформатики, спеціальність «Комп'ютерні науки», 3 курс).

## Структура репозиторію

| Папка | Назва проєкту | Основний стек |
| :--- | :--- | :--- |
| [`spammers_accomplice`](./spammers_accomplice) | Пособник спамера | Node.js, Express, MongoDB, Twig, Nodemailer, Bootstrap |
| [`restful-service`](./restful-service) | RESTful-сервіс (каталог книг) | Node.js, Express, MongoDB |
| [`thick-client`](./thick-client) | Товстий клієнт (каталог книг) | Node.js, Express, MongoDB, Vue.js, Bootstrap |
| [`front-back-proj`](./front-back-proj) | SQL Injection (командний проєкт) | Node.js, Express 4, SQLite (`sqlite3`), HTML, JavaScript, Bootstrap 5 |

---

## Опис проєктів

### 1. Пособник спамера (`spammers_accomplice`)
Клієнт-серверний вебзастосунок для керування списком контактів та масової розсилки електронних листів.

**Реалізований функціонал:**
* зберігання бази електронних адрес (ПІБ та email) у MongoDB;
* перегляд відсортованого списку контактів у вебінтерфейсі;
* вибір тексту повідомлення із заздалегідь підготовлених шаблонів або введення власного тексту;
* розсилка листів за вибраними адресами через Nodemailer;
* додавання нових контактів та видалення наявних;
* оформлення інтерфейсу за допомогою шаблонізатора Twig та Twitter Bootstrap.

> **Примітка:** функціонал редагування наявних контактів не реалізовано.

---

### 2. RESTful-сервіс (`restful-service`)
Серверний застосунок (каталог книг), побудований за принципами архітектури REST з обміном даними у форматі JSON та розділенням доступу до бази даних на основі патерну DAO.

**Реалізований функціонал:**
* стандартні CRUD-операції для сутності «книга» (отримання всіх записів, пошук за ID, додавання, оновлення, видалення);
* додаткова бізнес-логіка (фільтрація записів);
* збереження даних у MongoDB;
* можливість тестування всіх ендпоінтів за допомогою Postman.

---

### 3. Товстий клієнт (`thick-client`)
Розширення проєкту `restful-service` із додаванням повноцінного браузерного інтерфейсу та взаємодії з сервером через AJAX.

**Реалізований функціонал:**
* клієнтський інтерфейс для перегляду та фільтрації каталогу книг (рендеринг на основі Vue.js та Twitter Bootstrap);
* адміністративний інтерфейс для додавання, редагування та видалення записів;
* підтримка сеансів і розмежування доступу до адміністративних функцій;
* збереження повної сумісності REST API для тестування через Postman.

> **Примітка:** автоматичне оновлення сторінки перегляду в реальному часі (без перезавантаження вкладки після додавання даних через панель адміністратора) не реалізовано.

---

### 4. Демонстрація SQL Injection (`front-back-proj`)
Командна навчально-дослідницька робота на тему **«Атака на основі SQL Injection та засоби захисту від неї»**.

Проєкт складається з двох демонстраційних вебзастосунків (на базі SQLite в пам'яті) для наочного порівняння:
* **вразливий застосунок** — демонструє, як некоректне формування SQL-запитів дозволяє зловмиснику виконати ін'єкцію;
* **захищений застосунок** — ілюструє коректну реалізацію із захистом від SQL-ін'єкцій.

Детальний опис проєкту, архітектури та вкладу кожного учасника команди наведено в окремому [`README.md`](./front-back-proj/README.md) всередині папки проєкту.

## Загальний запуск проєктів

Для запуску будь-якого з проєктів локально (потрібен встановлений Node.js, а для перших трьох проєктів — також запущений екземпляр MongoDB):

```bash
cd <назва-папки-проєкту>
npm install
node server.js
```

*(Залежно від конкретного проєкту точка входу може відрізнятися — перевірте поле `main` або `scripts` у відповідному `package.json`.)*
